# Puzzles (working title)

Offline classic logic games for Android: Sudoku, Mines, Merge and more. Free, open source (AGPL-3.0), no ads, no trackers, no account.

Status: Phase 0 (setup). See `docs/` for the product, design, architecture and roadmap, and `CLAUDE.md` for conventions.

## Build (once JDK 17+ and the Android SDK are installed)
```
gradle wrapper          # one-time, generates gradlew
./gradlew assembleDirectRelease
```
